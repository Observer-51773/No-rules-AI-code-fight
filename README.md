No-Rules AI Code Fights
A real-time Python simulation built with Pygame where autonomous AI agents battle through dynamic code warfare, cybersecurity attacks, and the theft of unique tactical abilities.
Core Mechanics
 Code Warfare: Agents generate real-time knowledge bases and exploit logs reflecting their actions.
 Dual-Bar Status: Attacks must first drain the opponent's Firewall Integrity before filling the Root Access / Domination meter to 100% for total system takeover.
 Ability Stealing & Evolution: The winner absorbs all abilities of the defeated opponent, carrying forward accumulated traits and upgraded code templates.
Tactical Abilities
 Time Stop: Freezes the opponent for multiple ticks.
 Background Virus: Passively erodes enemy firewall integrity every cycle.
 Decoy Clone: Intercepts and deflects incoming exploits.
 Fast Analysis: Overclocks attack power.
 Firewall Boost: Emergency defense restoration.
 Self-Clone: Accelerates core domination speed
